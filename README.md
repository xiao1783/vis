# VisLab 可视化学习实验室 · 《可视化导论》交互式学习网站

对原课程网站 <https://cinger007.github.io/vis/> 的重构版。保留五章 27 小节的课程范围，
把内容重新组织为“**课程总览 → 章节目标 → 小节学习 → 交互实验 → 即时自测 → 复习继续**”的完整自学闭环，
并为每个小节配套可操作的可视化实验。纯静态、无后端、无账号、无数据库，**站内不含任何视频**。

## 一、本地运行

> 站点通过 `fetch` 加载 `data/` 下的 CSV/JSON，直接双击 `index.html`（`file://`）会因浏览器安全策略导致数据加载失败，请用本地服务器打开。

在本目录（`index.html` 所在目录）执行：

```bash
# 方式一：Python 3（推荐）
python -m http.server 8123

# 方式二：Node.js
npx serve .
```

然后浏览器访问 <http://localhost:8123/index.html>。

## 二、部署到 GitHub Pages

1. 将本目录全部内容推送到 GitHub 仓库（如 `username.github.io/vis` 或任意仓库）。
2. 仓库 **Settings → Pages → Source** 选择 `main` 分支根目录 `/ (root)`。
3. 等待约 1 分钟，访问对应 Pages 地址即可。
4. 所有资源均为相对路径，数据与脚本会随站点一起加载，**无需任何外部服务或密钥**。

## 四、功能清单

- **课程总览与学习路线**：首页五章主线（认识数据 → 理解流程 → 选择颜色 → 表达低维数据 → 分析时间变化），每章卡片展示学习目标、小节数与完成状态。
- **章节总览**：本章要解决的问题、学习目标、前置知识、小节路径与代表实验。
- **小节学习页**：本节问题、核心结论、概念讲解、案例、关键代码（可复制）、易错点、小节自测、上一节/下一节。
- **6 个重点交互实验**：
  1. 数据变换流水线（filter → map → rollup，输入/操作/输出三列对照）；
  2. Data Join 三态（按 key 匹配，含等长数组 `[A,B,C]→[B,C,D]` 同时出现 enter/exit 的关键场景）；
  3. 可视化流程联动（五节点可点、聚合维度切换，树图同步更新）；
  4. 配色语义（类别/顺序/发散三场景，选对选错都给出原因）；
  5. 比例尺与曲线（线性 vs 对数；曲线插值 vs 最小二乘拟合，始终保留原始点）；
  6. 时序多视图（折线/日历热图/周内周期，真实日度数据，三图联动选日期）。
- **其余 21 个适配演示**：CSV 加载、DIKW 金字塔、属性×通道、多层聚合、树布局、可折叠树、
  颜色模型与 Lab 色域、色系搭配、经典调色板、配色对错、CVD 模拟、宽长表、倾角感知、
  Marching Squares、时间属性、人名折线、螺旋图、Storyline 等。
- **全站搜索**：覆盖中文标题、英文术语与缩写（如 Data Join、colormap、CVD、scaleTime），按 `/` 快速聚焦。
- **命令面板（Ctrl/⌘+K）**：任意页面一键呼出居中搜索浮层，↑↓ 选择、Enter 跳转、Esc 关闭。
- **错题回顾与薄弱点追踪**：自测记录每题对错，学习页提示答错题号，章节总览标记「待巩固 N 题」。
- **学习笔记**：每小节底部可折叠笔记区（自动保存），notes.html 汇总全部笔记并支持搜索。
- **代码参数即实验**：1.4 / 4.2 / 4.3 / 5.1 四节的讲解代码变成可拖动的参数控件，即时看到 D3 API 输出。
- **概念关联图**：首页知识地图以力导向图展示 27 个小节的依赖关系，节点可点击直达小节。
- **学习进度 / 收藏 / 自测**：访问、掌握、收藏三态区分，自测即时反馈并记录成绩，"继续学习"回到上次小节。
- **响应式**：宽屏三栏（讲解与实验并排），中屏目录收起，手机端目录与菜单进入抽屉。

## 五、学中交互：五个交互功能说明

围绕「在学中交互，在交互中学」的目标，在不影响原有内容的前提下新增以下五个功能。
全部数据仅存于当前浏览器 localStorage，无后端、无账号。

### 1. 全局命令面板（Ctrl/⌘+K）

- **入口**：任意页面按 `Ctrl+K`（Windows）或 `⌘+K`（macOS）；点击遮罩或按 `Esc` 关闭。
- **行为**：复用全站搜索索引，输入关键词即时过滤；`↑`/`↓` 移动高亮、`Enter` 跳转、鼠标点击直达。
- **实现**：[shell.js](assets/js/shell.js) `initCmdPalette()` 动态创建 `#cmd-palette` 浮层，样式在 ui.css `.cmd-*` 系列。

### 2. 错题回顾与薄弱点追踪

- **记录**：学习页自测全部作答后，[store.js](assets/js/store.js) `recordQuizDetail()` 将每题对错数组写入 `quizDetail`。
- **学习页提示**：答错时自测区上方出现琥珀色提示条，列出答错题号，建议重读后重做（lesson.js `renderWeakHint()`）。
- **章节页标记**：章节总览对应小节行显示「待巩固 N 题」徽章（chapter.js）。
- **重置**：点「重新作答」清空本次作答，但历史错题记录保留，下次全对后自动更新。

### 3. 学习笔记与概念卡片

- **小节内笔记**：每个学习页底部有「学习笔记」折叠卡片，textarea 输入后 400ms 防抖自动保存，显示「已保存 HH:MM」。
- **笔记总览**：`notes.html`（首页「我的笔记」按钮进入）按章节分组列出全部笔记，支持关键词搜索，点击可跳回对应小节。
- **实现**：store.js `setNote()` / `getNote()` / `getAllNotes()`；notes.js 渲染列表。

### 4. 代码参数即实验（Code Playground）

- **覆盖小节**：1.4 数据映射（scaleLinear / scaleBand / scaleOrdinal 三标签页）、4.2 比例尺（线性 vs 对数）、4.3 曲线（插值类型切换）、5.1 时间比例尺。
- **行为**：讲解区代码块下方出现「代码参数即实验」卡片，拖动滑块/切换下拉即重新执行对应 D3 代码，SVG 图形与数值结果同步更新。
- **实现**：[code-playground.js](assets/js/code-playground.js) 按小节 ID 注册渲染函数，lesson.js 在匹配小节自动挂载 `#pg-slot`。

### 5. 概念关联图（知识地图）

- **位置**：首页「课程目录」下方的知识地图区块。
- **内容**：27 个小节为节点（按章节着色，实心=已完成），25 条先修/关联边为连线，D3 力导向布局自动排布。
- **交互**：悬停显示小节标题，点击节点直达对应学习页；图例区分章节颜色与完成状态。
- **实现**：[home.js](assets/js/home.js) `LINKS` 定义依赖关系，`d3.forceSimulation` 渲染。

## 六、第二轮功能优化

在已有 5 个交互功能基础上，再补充以下 10 项能力，形成「学习 → 自测 → 错题 → 复习 → 统计 → 备份」的完整闭环。

### 1. 错题重做页（review.html）

- **入口**：学习页薄弱点提示中的「去错题本重做 →」；或命令面板搜索「错题」。
- **行为**：汇总所有小节答错的自测题，每题独立卡片；答错不锁定正确答案，可重试；做对后自动移出错题本并弹出提示。
- **实现**：[review.js](assets/js/review.js) 调用 `Store.getAllWeakPoints()` 渲染；答对后 `Store.resolveWeakPoint()` 从 `quizDetail` 中移除该题。

### 2. 学习数据导出 / 导入 / 清除

- **入口**：`stats.html` 页面底部的「学习数据管理」；或命令面板直接执行。
- **行为**：导出包含进度、收藏、自测、错题、笔记的 JSON 备份文件；导入可恢复数据（自动刷新页面）；清除需二次确认。
- **实现**：[common.js](assets/js/common.js) `exportData()` / `importData()` / `resetData()`，底层调用 [store.js](assets/js/store.js) `exportState()` / `importState()` / `resetAll()`。

### 3. 命令面板升级为「真命令」

- **入口**：任意页面 `Ctrl/⌘+K`。
- **行为**：空查询时显示「命令」分组（去错题重做 / 学习统计 / 我的笔记 / 导出 / 导入 / 清除数据）；在学习页额外出现「标记本节已掌握」「重置本节自测」「记笔记」三条上下文命令。
- **实现**：[shell.js](assets/js/shell.js) `cmdActions()` 生成命令列表，页面上下文命令通过 `vll:cmd` 自定义事件分发到 lesson.js。

### 4. 知识地图：薄弱节点 + 前置链高亮

- **行为**：有待巩固错题的节点外围显示琥珀色虚线圈；鼠标悬停任意节点时，其所有前置小节保持高亮、其余节点与连线变暗，帮助定位学习路径。
- **实现**：[home.js](assets/js/home.js) 遍历 `LINKS` 反向回溯构建祖先集合，配合 CSS `.dim` / `.chain` 类切换透明度。

### 5. 首页「今日复习建议」

- **位置**：首页课程目录区的总进度条下方。
- **行为**：优先列出有待巩固错题的小节；其次列出「超过 3 天访问但未标记掌握」的小节，最多 3 条，点击直达对应学习页。
- **实现**：[home.js](assets/js/home.js) 基于 `Store.getLessonWeakPoints()` 与 `Store.lastVisitDate()` 计算。

### 6. 参数实验室扩点

- **新增小节**：2.1 聚合维度（按专业/性别分组计数）、3.2 配色语义（类别/顺序/偏差三场景 × 配色方案联动）。
- **原有覆盖**：1.4 数据映射、4.2 比例尺、4.3 曲线、5.1 时间比例尺，总计 6 个小节。
- **实现**：[code-playground.js](assets/js/code-playground.js) 按小节 ID 注册渲染函数。

### 7. 学习页快捷键

- **按键**：`j` 下一节、`k` 上一节、`m` 标记/取消掌握、`n` 展开并聚焦笔记框。
- **保护**：焦点在输入框/textarea/select 或命令面板打开时不触发。
- **实现**：[lesson.js](assets/js/lesson.js) 全局 `keydown` 监听。

### 8. 学习统计仪表盘（stats.html）

- **内容**：总进度 / 待巩固错题数 / 笔记数 / 收藏数四张卡片；五章完成度条形图；按正确率排序的自测记录表。
- **实现**：[stats.js](assets/js/stats.js) 从 Store 聚合数据渲染。

### 9. 笔记 #标签

- **行为**：在笔记文本中写 `#标签`（如 `#比例尺`），`notes.html` 顶部自动出现标签筛选按钮；点击标签仅显示含该标签的笔记，可一键清除筛选。
- **实现**：[notes.js](assets/js/notes.js) `extractTags()` 解析文本中的 `#` 标签。

### 10. 笔记导出 Markdown

- **入口**：`notes.html` 顶部「导出 Markdown」按钮。
- **行为**：按章节分标题导出全部笔记为 `.md` 文件，便于归档或提交作业。
- **实现**：[notes.js](assets/js/notes.js) 组装 Markdown 字符串并触发浏览器下载。

## 七、概念校正（相对原站的两点重要修正）

- **Data Join**：使用 key 匹配时，即使新旧数组长度相同，也可能同时出现 enter、update、exit；
  三态由“身份”决定，与数量无关。1.5 节专门用等长替换示例说明。
- **曲线插值 ≠ 统计拟合**：D3 的曲线类型（natural/basis/monotoneX 等）只在采样点之间插值，
  可能制造数据中不存在的峰谷；它不代表回归分析。4.3 节同时提供“线性回归拟合线”对照。

## 八、存储与隐私

- 学习进度、收藏、自测成绩、**每题对错详情（quizDetail）、全部笔记（notes）与最近访问日期（visitLog）**仅写入**当前浏览器的 localStorage**（键名 `vll.progress.v1`），
  清除浏览器数据或更换设备后不会保留，不涉及任何账号、上传或云端同步。
- 为控制服务器存储空间，**站点不包含任何 MP4/WebM 等视频文件**；所有图示均由 SVG/D3 实时绘制。
- 教学数据均为小样本：`newstudent.csv` 为**合成数据**，页面会持续标注“AI 合成”，不可用于真实人口分析。
- 站点可以离线运行：D3 已本地打包，所有脚本与数据均为站内相对路径。

## 九、技术栈

HTML + CSS + 原生 JavaScript（普通 `<script>`，无构建工具）+ [D3 v7](https://d3js.org/)。
数据处理使用 d3-dsv / d3-array，图形使用 d3-selection / d3-shape / d3-scale / d3-contour / d3-geo 等。

## 十、已知限制

- 学习状态不跨设备同步（按设计）。
- 搜索仅覆盖小节标题、关键词与概念摘要，不做全文检索（第一版范围）。
- CVD（色觉缺陷）模拟为线性近似，用于预判，不能替代真实用户测试。
- 时序实验仅提供 2024 年一年日度数据，未做跨年份对比。

## 十一、交互体验优化（2026-10-19）

- 六个重点实验共用三步学习引导、根据当前状态生成的情境自测、撤销/重做与初始参数恢复；窄屏默认折叠学习引导，方便直接操作。
- 实验参数自动保存在当前浏览器的 `vll.lab.v1.*` 键中，刷新后恢复。历史最多保留本次页面内的 40 个状态；一次拖动作为一个操作。参数暂不包含在学习数据 JSON 备份中。
- Data Join：点击数据项/圆点联动编辑对象和对应代码，支持匹配、退出、更新、进入、完成五阶段的单步、播放和暂停。
- 比例尺与曲线：点击人口标记、直接拖动线性/对数轴，联动数值和映射代码；曲线点支持鼠标/触屏拖动和上下键调整。轴支持左右键、Home/End。
- 时序多视图：开启范围框选后在折线上拖动，或用起止日期输入；范围天数、平均气温、日历高亮和星期汇总联动。清除范围恢复全年统计，清除日期选择独立生效。
- 原有“保存对照”保留为静态画面，不参与实时操作；实验存储失败时明确提示，本次操作与撤销仍可用。

验证方式：启动本地 HTTP 服务器后，执行 `node --test tests/*.test.cjs`；在可加载 Playwright 且 Chromium 可用的环境中，执行 `node tests/learning-experience.browser.cjs`。浏览器测试覆盖六个实验、拖动/框选、撤销重做、刷新恢复、无效存储、存储失败、键盘、390px 布局和模拟触屏手势。可通过 `VIS_TEST_URL` 指定站点地址、`VIS_TEST_OUTPUT` 指定截图目录。
